Program 02 - Read a Character

Problem Statement

Write a C program to read a character from the keyboard and display it on the screen.

Logic

The scanf() function is used to read character from the keybord.
The printf() function is used to display the character on the screen.

Source Code

#include <stdio.h>

void main()
{
	char a;

	printf("Enter a character : ");
	scanf("%c",&a);

	printf("You entered: %c",a);
}

Output

C:\C_PROGRAMS>program02.exe

Enter a character : A

You entered: A
