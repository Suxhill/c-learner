Program 01 - Print First C Program Message

Problem Statement

Write a C program to print the message :
Today i made my first C program.

Logic

The printf() function is used to display the given message on the screen.

Source Code

#include <stdio.h>

void main()
{
	printf("Today i made my first C program.");
}

Output

C:\C_PROGRAMS>program01.exe

Today i made my first C program.
