Program 01 - Capital Data Only

Problem Statement

Enter file name and data from user and put data in file but data should be in capital letter.

Source Code

#include <stdio.h>

void main()
{
    char f[10], data[30];
	int i;
	FILE * New;
	printf("Enter file name: ");
	gets(f);
	printf("Enter the data: ");
	gets(data);

	New = fopen(f,"w");
	for(i = 0; data[i] != '\0'; i++)
	{
		if(data[i] >= 'a' && data[i] <= 'z')
		data[i] = data[i] - 32;
	}
	fprintf(New , "%s", data);
	fclose(New);
	printf("\nData entered successfully!");

}
