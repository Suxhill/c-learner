Program 06 — Print Your Name 5 Times with Blinking Effect

Problem Statement

Write a C program to print your name on the output screen with a blinking effect 5 times.

Logic

The printf() function displays the name, delay() pauses execution, and clrscr() clears the screen before the next display.

Source Code

#include <stdio.h>
#include <conio.h>

void main()
{
	int i;

	for(i=1; i<=5; ++i)
	{
		clrscr();
		delay(250);
		printf("Sushil");
		delay(500);
	}
}

Output

Sushil
