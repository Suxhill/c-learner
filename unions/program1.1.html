Program 01 - Store and Display Student Details

Problem Statement

Write a program to store and display student details using a union.

Source Code

#include <stdio.h>

union stu{
	int roll;
	float marks;
	char grade;
};

void main()
{
	union stu s;

	s.roll = 4087;
	printf("\nRoll no. = %d\n", s.roll)

	s.marks = 84.4;
	printf("Marks = %f\n", s.marks);

	s.grade = 'A';
	printf("Grade = %c\n", s.grade);
}
