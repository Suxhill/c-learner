Program 02 - Store and Display Employee ID

Problem Statement

Write a program to store and display student details using a union.

Source Code

#include <stdio.h>

union emp{
	int id;
	float salary;
	char grade;
};

void main()
{
	union emp e;

	e.id = 103;
	printf("\nEmployee ID = %d\n", e.id)

	e.salary = 25000.50;
	printf("Employee Salary = %f\n", e.salary);

	e.grade = 'A';
	printf("Employee Grade = %c\n", e.grade);
}
