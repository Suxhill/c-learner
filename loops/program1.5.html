Program 05 - Print Your Name 1 Lakh Times

Problem Statement

Write a program to print your name 1 lakh times.

Logic

Use a for loop to print the name 100000 times.

Source Code

#include <stdio.h>

void main()
{
	int i;

	for(i = 1; i <= 100000; i++)
	{
		printf("Sushil\n");
	}
}
