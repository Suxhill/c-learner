Program 03 - Read 4 Characters

Problem Statement

Write a C program to read four characters from the keyboard and display them on seperate lines.

Logic

The scanf() function is used to read four characters from the keybord.
The printf() function with \n is used to display each character on a seperate line.

Source Code

#include <stdio.h>

void main()
{
	char ch1,ch2,ch3,ch4;

	printf("Enter four characters(using space):")
	scanf("%c %c %c %c",&ch1,&ch2,&ch3,&ch4);

	printf("\nYou entered :\n%c \n%c \n%c \n%c",ch1,ch2,ch3,ch4);	
}
